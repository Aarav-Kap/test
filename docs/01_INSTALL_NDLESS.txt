01 — INSTALL NDLESS r2022
=========================

This is intentionally the only calculator modification in this project.

REQUIREMENTS
------------
- TI-Nspire CX II-T (non-CAS)
- OS exactly 6.4.0.74
- Battery charged
- Back up important documents first

CURRENT COMPATIBILITY
---------------------
Ndless r2022 added support for OS 6.4.0.74 on:
- CX II
- CX II-T
- CX II CAS

SAFE BOUNDARY FOR THIS PROJECT
------------------------------
We are NOT using:
- Boot2 flashing
- NAND flashing
- nLoader
- firmware downgrades
- stealth/exam-mode modifications

INSTALL
-------
1. Download Ndless r2022 from the official ndless-nspire/Ndless GitHub Releases.
2. Read the README included in that release.
3. Transfer the required installer/resources files into the folder the release
   README specifies.
4. Run the installer on the calculator.
5. Verify the "Ndless installed" indication appears.
6. Test one harmless homebrew app before NspireAI.

Official release page:
  https://github.com/ndless-nspire/Ndless/releases/tag/r2022

If the files/instructions on the release page differ from an old YouTube video,
follow the current release README, not the old video.

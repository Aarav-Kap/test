02 — WINDOWS AI SETUP
=====================

A. PYTHON
---------
Install Python 3.11 or newer on Windows.
During installation, enable the option to add Python to PATH if offered.

Then run:
  host\FIRST_TEST.bat

The MOCK provider proves bridge.py works without any account or internet API.

B. OPENAI OPTION
----------------
ChatGPT Plus and API billing are separate.

1. Create an API key on the OpenAI API platform.
2. Do NOT save the key inside this ZIP.
3. Edit host\config.json:
     "provider": "openai"
4. Set OPENAI_API_KEY in Windows.
5. Test:
     py -3 host\bridge.py test "Explain the quotient rule."

The package defaults to gpt-5.6-luna because it is the lower-cost member of the
current GPT-5.6 family. You can change the model in config.json.

C. OLLAMA OPTION
----------------
If you don't want API usage, install Ollama on Windows and run a small local
model. A 4B model is a reasonable first experiment, but actual speed depends on
your PC hardware.

Edit:
  "provider": "ollama"

Then test the bridge again.

D. CONTINUOUS BRIDGE
--------------------
Double-click:
  host\RUN_BRIDGE.bat

It watches host\exchange for new request.tns files.
